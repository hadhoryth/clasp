# Clasp logo

`logo.png` is the original project mark used in the README and Codex plugin interface: coral and mint terminal brackets with a rightward bridge on a navy tile. It is an independent project identity and does not use the Anthropic or OpenAI logos. Distributed under this repository's MIT license.

Created with the built-in ImageGen tool in generation mode before the project was renamed Clasp. Original prompt:

> Use case: logo-brand. Create one polished original logo icon for an open-source developer CLI called Claude to Codex, a local compatibility bridge between coding tools. Asset is a small GitHub README and package icon. Design a compact, distinctive geometric mark: two opposing rounded terminal brackets joined by a clear rightward bridge/arrow. Warm muted coral on the left, cool mint on the right, on a deep midnight navy rounded-square tile. Flat vector-like graphic, bold clean strokes, excellent readability at 64px, precise symmetry and optical spacing, generous padding. Square composition, 1024x1024, tile fully visible, transparent area outside the rounded tile. No text, letters, wordmark, gradients, 3D, shadows, texture, tiny details or watermarks. Do not imitate the Anthropic or OpenAI logos. Final asset suitable for an independent developer project.
